# Provider-neutral RVEH I5 handoff

An evaluator may use local hardware, a VM or container, GitHub Actions, GitLab CI, Railway, Vercel, Hugging Face, or another environment under evaluator control. Provider choice alone does not establish independence.

Return evaluator identity and affiliation, evidence of independence from target development, both frozen target identities, evaluator-controlled execution or adjudication, environment and method, preserved raw evidence with SHA-256, and a PASS, FAIL, or BLOCKED verdict with reasoning.

Incoming evidence is RECEIVED_UNVERIFIED until validation. Adverse results are retained and acceptance criteria must not be weakened.
